# CityScout - 현실 도시 환경 분석 에이전트

CityScout은 현실 세계의 지형 데이터를 마인크래프트 월드로 변환하여 보행로 접근성과 일조권을 시뮬레이션하고 분석하는 도구입니다.

## 1. 개요
도시 계획자와 건축가가 가상 공간에서 실제 도시 환경을 사전에 테스트하고 최적의 설계를 할 수 있도록 지원합니다.

## 2. 주요 기능
- **데이터 업로드**: GeoJSON, Shapefile 등 지형 데이터 파일 업로드.
- **3D 변환**: Arnis 엔진을 활용한 마인크래프트 월드 생성.
- **접근성 분석**: 보행자 이동 경로, 경사도, 장애물 분석.
- **일조권 분석**: 시간별/계절별 그림자 시뮬레이션.
- **결과 대시보드**: Three.js를 활용한 인터랙티브 3D 시각화 및 리포트 제공.

## 3. 사용자 여정
1. **홈**: 서비스 소개 및 시작.
2. **업로드**: 분석할 지형 파일 선택.
3. **변환**: 데이터 처리 과정 시각화.
4. **대시보드**: 분석 결과 확인 및 3D 모델 탐색.
